NexaTrans 1.2 - 安装说明
========================

实时 AI 屏幕翻译工具（游戏/截图文字一键翻译）。

【运行要求】
- Windows 10/11 (64 位)
- 首次运行需要联网：程序会自动下载 AI 模型（检测 + 识别，约 75MB），
  下载完成后即可离线使用。本机若已使用过，模型已在缓存中，可直接使用。

【配置 DeepSeek 翻译密钥】
1. 打开安装目录下的 .env 文件（或程序设置面板）。
2. 填入 DEEPSEEK_API_KEY=你的密钥
3. 保存后重启程序。也可在程序“设置”里直接填写并测试连通性。

【说明】
- 配置、日志、翻译缓存保存在安装目录（当前用户可写位置）。
- 通过“开始菜单”或桌面快捷方式启动。
- 卸载请使用系统“应用和功能”中的卸载项。
